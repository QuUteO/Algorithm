# Algorithms & Data Structures — Сборник алгоритмов на Go

Репозиторий представляет собой библиотеку классических алгоритмов и структур данных, реализованных на языке Go. Цель этого сборника — консолидация фундаментальных знаний в области Computer Science, разбор их пространственной и временной сложности, а также практика написания чистого, эффективного и идиоматичного Go-кода.

## Структура репозитория

Каждый алгоритм или структура данных вынесены в отдельную изолированную директорию, содержащую саму реализацию и подробное теоретическое описание (`README.md`).
